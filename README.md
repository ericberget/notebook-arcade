# Notebook Arcade

Little games that look like ballpoint pen and pencil doodles on notebook paper.

- **Doodle Slingshot** — fling angry doodles at scribbled towers (ruled paper)
- **X's & O's Football** — draw up the play, hike, throw or hand it off, steer the runner (spiral sketchpad)
- **Paper Football** — flick the folded triangle (legal pad)

Open `index.html`, or run `node serve.js` and visit http://localhost:8791.

`shared/paper.js` holds the paper styles, `shared/ink.js` the sketchy drawing helpers.
